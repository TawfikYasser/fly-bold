LOCAL Client Batch Size & Epoch Modulation

To prevent noisy gradient stagnation and boost client efficiency:

  • Start Minimal: Clients launch local training with $\beta = \beta_{min}$ for time and memory speed.
  • RMD Watch ($\rho$): Monitors relative model weight updates over epochs. Low $\rho$ signals learning stagnation.
  • Adaptive Triggers:
    if (RMD stalled OR Loss_epoch > Loss_prev_epoch):
      Increase Batch Size β;
      Reduce Gradient Noise variance;
  • Early Termination: If validation criteria mandate a higher $\beta$ than $\beta_{max}$, local epochs are safely halted early to preserve compute budget.

GLOBAL Server Learning Rate Search

To maximize communication efficiency and secure fast convergence:

  • Commence Safe: Launches initially with $\lambda = \lambda_{min}$.
  • Aggressive Exploration: If global validation loss decreases compared to the previous round, we safely increase $\lambda$ to take larger convergence strides.
  • Decisive Boundary Shrinkage:
    if (Val_Loss_round > Val_Loss_prev_round):
      λ_max = previous_successful_λ;
      λ = fallback_to_safe_low_value;
      h_λ++ (LR reduction counter);
  • Halt Check: Training rounds terminate once $H_\lambda$ maximum reductions threshold is saturated.
