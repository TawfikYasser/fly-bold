Aggregator Formula

Server strategy: FedAdam

Aggregates models with momentum & step normalization to stabilize edge descent.

1. Client Update Difference: Δt,i = wt,i - wt
2. Weighted Aggregation: Δt = Σ (ni/N) Δt,i
3. Momentum & Second Moment Updates: mt = β1mt-1 + (1-β1)Δt vt = β2vt-1 + (1-β2)Δt2
4. Server Update: wt+1 = wt + η · mt / (√vt + τ)
β1 Momentum 0.90
β2 Moment 0.99
Server Step η 0.10
Stability τ 1e-3
