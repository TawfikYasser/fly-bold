# Flybold

Federated Learning Benchmark Framework for Object Detection with YOLOv5 on COCO in GCP.

## Overview
Flybold is a comprehensive benchmark framework designed to facilitate federated learning experiments for object detection tasks using the YOLOv5 model on the COCO dataset. This framework is optimized for deployment on Google Cloud Platform (GCP), enabling researchers and developers to easily set up, run, and evaluate federated learning scenarios.

## Features
- **Federated Learning Support**: Seamlessly integrates federated learning protocols to train YOLOv5 models across multiple clients.
- **YOLOv5 Integration**: Utilizes the state-of-the-art YOLOv5 model for high-performance object detection.
- **COCO Dataset Compatibility**: Built to work with the COCO dataset, a widely used benchmark for object detection tasks.  
- **Google Cloud Platform (GCP) Deployment**: Optimized for easy deployment and scalability on GCP infrastructure.
- **Benchmarking Tools**: Provides tools to evaluate model performance, communication efficiency, and training dynamics in federated settings.
- **Customizable Configurations**: Allows users to customize various parameters such as the number of clients, data distribution, and training settings.
